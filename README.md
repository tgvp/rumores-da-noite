# Rumores da Noite

**One city. Many versions of the same story.**

Rumores da Noite ("Rumours of the Night") is an independent interactive fiction project set in an imagined version of Lisbon. Through a fictional social network, it presents rumours, conflicting eyewitness accounts and conversations about events across the city, creating a narrative for readers and players to explore.

🌙 **[Explore Rumores da Noite](https://tgvp.github.io/rumores-da-noite/)**

## What you will find

- Communities discussing city life, nightlife and other topics.
- Posts, fictional profiles and nested comments.
- Different interpretations of the same events.
- Light and dark themes.
- A fiction disclaimer on entry, including direct links to individual posts.

The users, comments and scores are part of the narrative. This version is read-only: visitors cannot create accounts, publish content or cast votes.

## Fiction disclaimer

**Rumores da Noite is an independent interactive fiction project set in an imagined version of Lisbon. All events, posts, comments and user accounts are fictional and have no connection to real events. Real locations are used only as a backdrop for storytelling. Nothing on this website should be interpreted as news, factual reporting or allegations about real people or organisations.**

The project is not affiliated with any real social network, news outlet or organisation depicted in its stories.

## About this repository

This repository contains the public static version of the website and its deployment workflow for GitHub Actions and GitHub Pages.

Content is prepared in a separate administration environment and exported to `site/`. The administration panel, credentials, database and private story notes are not included in this repository.

Updates pushed to `main` trigger a new deployment. The website displays the latest exported content and does not require a permanent connection to the administration environment.

## Analytics

The website may use Cloudflare Web Analytics to measure visits and page views. These metrics are independent of the fictional accounts and scores and do not identify individual readers. Content blockers and measurement limitations may affect the results.
